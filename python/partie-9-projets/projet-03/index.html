Projet 03 : Gestionnaire de tâches professionnel (POO, Persistance JSON et Tests Pytest)#

Dans l'industrie logicielle contemporaine, savoir écrire des scripts isolés est utile, mais concevoir une architecture logicielle robuste, maintenable et testable est la véritable marque d'un développeur professionnel.

Ce troisième et dernier projet synthétise l'ensemble des compétences acquises tout au long du cours : Programmation Orientée Objet (POO), héritage et polymorphisme, gestion fine des dates (datetime), persistance sur disque au standard JSON, hiérarchie d'exceptions personnalisées et validation automatique par une suite de tests unitaires avec Pytest.

1. Cahier des charges et spécifications techniques#

Nous souhaitons développer le cœur applicatif d'un système de gestion de tâches (Task Manager) pour équipes de développement.

Spécifications fonctionnelles :#

  1. Modèle de données & Typage fort :
  2. Définition d'énumérations (enum.Enum) pour les statuts (A_FAIRE, EN_COURS, TERMINEE) et les niveaux de priorité (BASSE, MOYENNE, HAUTE, URGENTE).
  3. Classe de base Tache :
    • Identifiant unique auto-incrémenté.
    • Titre, description, date d'échéance (datetime.date), priorité et statut.
    • Propriété calculée est_en_retard : compare la date d'échéance à la date du jour si la tâche n'est pas encore terminée.
    • Méthodes de sérialisation to_dict() et de désérialisation from_dict().
  4. Spécialisation par Héritage (TacheUrgente) :
  5. Hérite de Tache.
  6. Force automatiquement la priorité à URGENTE.
  7. Possède un attribut supplémentaire responsable_alerte: str et une méthode dédiée emettre_rappel().
  8. Moteur de gestion (GestionnaireTaches) :
  9. Collection centrale de tâches encapsulée dans un dictionnaire interne { id: Tache }.
  10. Méthodes CRUD : ajout, consultation par identifiant, suppression, modification de statut.
  11. Filtrage : liste des tâches par statut, liste des tâches en retard de livraison.
  12. Persistance : méthodes sauvegarder(fichier: Path) et charger(fichier: Path) gérant les fichiers JSON.
  13. Exceptions métier dédiées :
  14. TacheNonTrouveeError : levée lorsqu'un identifiant inexistant est interrogé.
  15. StatutInvalideError : levée en cas de transition interdite ou de valeur inattendue.
  16. Couverture de tests avec Pytest :
  17. Mise en place de fixtures Pytest pour injecter des jeux de données isolés.
  18. Utilisation de tmp_path pour tester la lecture et l'écriture sur disque sans polluer l'espace de travail.
  19. Tests de conformité des exceptions avec pytest.raises.

2. Diagramme de classes UML#

Le modèle respecte le principe de responsabilité unique (SRP - Single Responsibility Principle) :

    Tache ..> StatutTache : Utilise

3. Implémentation du cœur applicatif (task_manager.py)#

Créez le fichier task_manager.py dans votre répertoire de projet :

"""
Système de gestion de tâches orienté objet avec persistance JSON.
Auteur : Joseph Konka (AlgoJungle)
"""

from __future__ import annotations
import json
from datetime import date, datetime
from enum import Enum
from pathlib import Path
from typing import Any, Dict, List, Optional


# =====================================================================
# 1. ÉNUMÉRATIONS ET EXCEPTIONS SUR MESURE
# =====================================================================

class StatutTache(str, Enum):
    """Énumération des statuts d'avancement possibles d'une tâche."""
    A_FAIRE = "À faire"
    EN_COURS = "En cours"
    TERMINEE = "Terminée"


class Priorite(str, Enum):
    """Énumération des niveaux de priorité d'une tâche."""
    BASSE = "Basse"
    MOYENNE = "Moyenne"
    HAUTE = "Haute"
    URGENTE = "Urgente"


class TaskManagerError(Exception):
    """Exception de base pour les erreurs du gestionnaire de tâches."""
    pass


class TacheNonTrouveeError(TaskManagerError):
    """Levée lorsqu'une tâche n'existe pas dans le registre."""
    pass


# =====================================================================
# 2. CLASSES MÉTIER : TACHE ET TACHEURGENTE
# =====================================================================

class Tache:
    """Représente une unité de travail élémentaire."""

    def __init__(
        self,
        titre: str,
        description: str,
        date_echeance: date,
        priorite: Priorite = Priorite.MOYENNE,
        statut: StatutTache = StatutTache.A_FAIRE,
        id_tache: Optional[int] = None,
    ) -> None:
        if not titre.strip():
            raise ValueError("Le titre de la tâche ne peut pas être vide.")

        self.id_tache: Optional[int] = id_tache
        self.titre: str = titre.strip()
        self.description: str = description.strip()
        self.date_echeance: date = date_echeance
        self.priorite: Priorite = priorite
        self.statut: StatutTache = statut

    @property
    def est_en_retard(self) -> bool:
        """Détermine si la tâche a dépassé son échéance sans être terminée."""
        if self.statut == StatutTache.TERMINEE:
            return False
        return date.today() > self.date_echeance

    def marquer_terminee(self) -> None:
        """Bascule le statut de la tâche à TERMINÉE."""
        self.statut = StatutTache.TERMINEE

    def to_dict(self) -> Dict[str, Any]:
        """Convertit l'instance en dictionnaire sérialisable au format JSON."""
        return {
            "type": "Tache",
            "id_tache": self.id_tache,
            "titre": self.titre,
            "description": self.description,
            "date_echeance": self.date_echeance.isoformat(),
            "priorite": self.priorite.value,
            "statut": self.statut.value,
        }

    @classmethod
    def from_dict(cls, data: Dict[str, Any]) -> Tache:
        """Reconstitue une instance de Tache à partir d'un dictionnaire brut."""
        return cls(
            id_tache=data.get("id_tache"),
            titre=data["titre"],
            description=data["description"],
            date_echeance=datetime.strptime(data["date_echeance"], "%Y-%m-%d").date(),
            priorite=Priorite(data["priorite"]),
            statut=StatutTache(data["statut"]),
        )

    def __repr__(self) -> str:
        retard = " ⚠️ EN RETARD" if self.est_en_retard else ""
        return (
            f"<Tache #{self.id_tache} [{self.priorite.value}] '{self.titre}' "
            f"({self.statut.value}){retard}>"
        )


class TacheUrgente(Tache):
    """Spécialisation d'une tâche avec protocole d'escalade d'urgence."""

    def __init__(
        self,
        titre: str,
        description: str,
        date_echeance: date,
        responsable_alerte: str,
        statut: StatutTache = StatutTache.A_FAIRE,
        id_tache: Optional[int] = None,
    ) -> None:
        super().__init__(
            titre=titre,
            description=description,
            date_echeance=date_echeance,
            priorite=Priorite.URGENTE,
            statut=statut,
            id_tache=id_tache,
        )
        self.responsable_alerte: str = responsable_alerte.strip()

    def emettre_rappel(self) -> str:
        """Génère un message d'alerte haute priorité."""
        return (
            f"🚨 RAPPEL CRITIQUE : La tâche #{self.id_tache} '{self.titre}' "
            f"doit être traitée d'urgence par {self.responsable_alerte} !"
        )

    def to_dict(self) -> Dict[str, Any]:
        data = super().to_dict()
        data["type"] = "TacheUrgente"
        data["responsable_alerte"] = self.responsable_alerte
        return data

    @classmethod
    def from_dict(cls, data: Dict[str, Any]) -> TacheUrgente:
        return cls(
            id_tache=data.get("id_tache"),
            titre=data["titre"],
            description=data["description"],
            date_echeance=datetime.strptime(data["date_echeance"], "%Y-%m-%d").date(),
            responsable_alerte=data["responsable_alerte"],
            statut=StatutTache(data["statut"]),
        )


# =====================================================================
# 3. GESTIONNAIRE CENTRAL DE TÂCHES
# =====================================================================

class GestionnaireTaches:
    """Service d'agrégation, de manipulation et de persistance des tâches."""

    def __init__(self) -> None:
        self._taches: Dict[int, Tache] = {}
        self._prochain_id: int = 1

    def ajouter_tache(self, tache: Tache) -> int:
        """Enregistre une nouvelle tâche et lui assigne un identifiant unique."""
        tache.id_tache = self._prochain_id
        self._taches[self._prochain_id] = tache
        self._prochain_id += 1
        return tache.id_tache

    def obtenir_tache(self, id_tache: int) -> Tache:
        """Retourne la tâche correspondant à l'identifiant ou lève une exception."""
        if id_tache not in self._taches:
            raise TacheNonTrouveeError(f"Aucune tâche trouvée avec l'ID #{id_tache}.")
        return self._taches[id_tache]

    def supprimer_tache(self, id_tache: int) -> None:
        """Supprime une tâche du registre."""
        if id_tache not in self._taches:
            raise TacheNonTrouveeError(f"Impossible de supprimer : ID #{id_tache} inexistant.")
        del self._taches[id_tache]

    def filtrer_par_statut(self, statut: StatutTache) -> List[Tache]:
        """Retourne toutes les tâches ayant un statut particulier."""
        return [t for t in self._taches.values() if t.statut == statut]

    def obtenir_taches_en_retard(self) -> List[Tache]:
        """Retourne toutes les tâches non terminées dont l'échéance est passée."""
        return [t for t in self._taches.values() if t.est_en_retard]

    def sauvegarder_json(self, chemin: Path) -> None:
        """Sérialise l'ensemble du registre dans un fichier JSON structuré."""
        export_data = {
            "prochain_id": self._prochain_id,
            "taches": [t.to_dict() for t in self._taches.values()],
        }
        with open(chemin, mode="w", encoding="utf-8") as f:
            json.dump(export_data, f, ensure_ascii=False, indent=4)

    def charger_json(self, chemin: Path) -> None:
        """Désérialise les données d'un fichier JSON et peuple le registre."""
        if not chemin.exists():
            raise FileNotFoundError(f"Le fichier '{chemin}' n'existe pas.")

        with open(chemin, mode="r", encoding="utf-8") as f:
            data = json.load(f)

        self._taches.clear()
        self._prochain_id = data.get("prochain_id", 1)

        for item in data.get("taches", []):
            if item.get("type") == "TacheUrgente":
                instance = TacheUrgente.from_dict(item)
            else:
                instance = Tache.from_dict(item)
            if instance.id_tache is not None:
                self._taches[instance.id_tache] = instance
