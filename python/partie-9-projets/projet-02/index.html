Projet 02 : Analyseur de données de ventes et reporting financier#

Dans les départements Data, Finance et Opérations, l'automatisation du traitement des fichiers d'exportation quotidienne est un cas d'usage fondamental. Bien que des bibliothèques externes spécialisées telles que Pandas existent, maîtriser la manipulation de données en pur Python standard sans dépendance externe est indispensable : cela permet de construire des microservices ultralégers, des fonctions Serverless (AWS Lambda, Google Cloud Functions) à démarrage instantané et des scripts système hautement portables.

L'objectif de ce deuxième projet est de construire un pipeline ETL (Extract, Transform, Load) complet capable de lire un fichier CSV de transactions commerciales, de nettoyer les données, d'agréger des indicateurs clés de performance (KPI) et de produire un rapport financier double : un affichage console élégant et un export structuré au standard JSON.

1. Cahier des charges fonctionnel#

Notre analyseur doit traiter un fichier de transactions de vente contenant les colonnes suivantes : id_commande, date, client, categorie, produit, quantite, prix_unitaire.

Exigences du traitement :#

  1. Extraction & Nettoyage robuste :
  2. Parcourir le fichier CSV avec le module standard csv.DictReader.
  3. Ignorer les lignes corrompues ou incomplètes sans faire planter le script (valeurs manquantes, quantités ou prix négatifs ou non convertibles).
  4. Convertir les données textuelles en types natifs appropriés (int pour les quantités, float pour les prix).
  5. Calculs analytiques & Métriques financières :
  6. Chiffre d'affaires brut total : somme des montants de chaque ligne (\(\text{quantite} \times \text{prix\_unitaire}\)).
  7. Nombre total de commandes uniques et nombre total d'articles vendus.
  8. Panier moyen par commande : \(\frac{\text{CA Total}}{\text{Nombre de commandes}}\).
  9. Ventilation par catégorie : montant des ventes, part en pourcentage du CA global et volume d'articles.
  10. Palmarès des clients (Top 3) : les 3 clients ayant généré le plus de valeur d'achat.
  11. Palmarès des produits (Top 3) : les 3 articles les plus vendus en volume unitaire.
  12. Double restitution des livrables :
  13. Restitution textuelle formatée avec des tableaux ASCII soignés en console.
  14. Export d'un résumé analytique prêt à l'emploi au format JSON (resume_ventes.json), encodé en UTF-8 et indenté.

2. Architecture du pipeline ETL#

flowchart TD
    A[Fichier ventes.csv] --> B[Module csv.DictReader]
    B --> C{Validation ligne par ligne}
    C -- Erreur de conversion ou donnee negative --> D[Journalisation avertissement & Ligne ignoree]
    C -- Ligne valide --> E[Conversion de types : int, float]
    E --> F[Agrégation en mémoire : dictionnaires de cumul]
    F --> G[Calcul des indicateurs agreges et pourcentages]
    G --> H[Tri et extraction des Top 3 Clients et Produits]
    H --> I[Rendu visuel formatee en console f-strings]
    H --> J[Export vers fichier resume_ventes.json]

3. Implémentation complète en Python 3.10+#

Voici le script complet, modulaire, typé et prêt à l'emploi. Il intègre une fonction d'auto-génération de données de test au premier lancement si le fichier source n'existe pas encore sur votre machine :

"""
Analyseur de données de ventes et générateur de reporting financier en pur Python.
Auteur : Joseph Konka (AlgoJungle)
"""

import csv
import json
from collections import defaultdict
from dataclasses import dataclass
from pathlib import Path
from typing import Any, Dict, List, Optional, Tuple


@dataclass
class Transaction:
    """Structure de données représentant une ligne de vente valide."""
    id_commande: str
    date: str
    client: str
    categorie: str
    produit: str
    quantite: int
    prix_unitaire: float

    @property
    def total_ligne(self) -> float:
        """Montant total généré par la ligne."""
        return self.quantite * self.prix_unitaire

def charger_et_nettoyer_ventes(chemin_csv: Path) -> Tuple[List[Transaction], int]:
    """
    Lit le fichier CSV, filtre les lignes invalides et retourne les objets Transaction.
    Retourne également le nombre de lignes ignorées.
    """
    if not chemin_csv.exists():
        raise FileNotFoundError(f"Le fichier source '{chemin_csv}' est introuvable.")

    transactions_valides: List[Transaction] = []
    lignes_ignorees: int = 0

    with open(chemin_csv, mode="r", encoding="utf-8") as f:
        lecteur = csv.DictReader(f)
        for num_ligne, ligne in enumerate(lecteur, start=2):
            try:
                quantite = int(ligne["quantite"])
                prix = float(ligne["prix_unitaire"])

                if quantite <= 0 or prix <= 0:
                    lignes_ignorees += 1
                    continue

                tx = Transaction(
                    id_commande=ligne["id_commande"].strip(),
                    date=ligne["date"].strip(),
                    client=ligne["client"].strip(),
                    categorie=ligne["categorie"].strip(),
                    produit=ligne["produit"].strip(),
                    quantite=quantite,
                    prix_unitaire=prix,
                )
                transactions_valides.append(tx)
            except (ValueError, KeyError):
                lignes_ignorees += 1

    return transactions_valides, lignes_ignorees


def analyser_donnees(transactions: List[Transaction]) -> Dict[str, Any]:
    """Agrège et calcule tous les indicateurs clés de performance (KPI)."""
    if not transactions:
        raise ValueError("Aucune transaction valide à analyser.")

    ca_total: float = sum(tx.total_ligne for tx in transactions)
    commandes_uniques: set[str] = {tx.id_commande for tx in transactions}
    total_articles: int = sum(tx.quantite for tx in transactions)
    panier_moyen: float = ca_total / len(commandes_uniques)

    # 1. Cumul par Catégorie
    ca_par_categorie: Dict[str, float] = defaultdict(float)
    articles_par_categorie: Dict[str, int] = defaultdict(int)

    # 2. Cumul par Client
    ca_par_client: Dict[str, float] = defaultdict(float)

    # 3. Cumul par Produit (volume)
    volume_par_produit: Dict[str, int] = defaultdict(int)

    for tx in transactions:
        ca_par_categorie[tx.categorie] += tx.total_ligne
        articles_par_categorie[tx.categorie] += tx.quantite
        ca_par_client[tx.client] += tx.total_ligne
        volume_par_produit[tx.produit] += tx.quantite

    # Construction du détail des catégories avec pourcentages
    synthese_categories: List[Dict[str, Any]] = []
    for cat, montant in sorted(ca_par_categorie.items(), key=lambda item: item[1], reverse=True):
        part_ca = (montant / ca_total) * 100 if ca_total > 0 else 0.0
        synthese_categories.append({
            "categorie": cat,
            "chiffre_affaires": round(montant, 2),
            "pourcentage_ca": round(part_ca, 2),
            "articles_vendus": articles_par_categorie[cat],
        })

    # Classements Top 3
    top_clients = sorted(ca_par_client.items(), key=lambda item: item[1], reverse=True)[:3]
    top_produits = sorted(volume_par_produit.items(), key=lambda item: item[1], reverse=True)[:3]

    return {
        "chiffre_affaires_total": round(ca_total, 2),
        "nombre_commandes": len(commandes_uniques),
        "total_articles_vendus": total_articles,
        "panier_moyen": round(panier_moyen, 2),
        "categories": synthese_categories,
        "top_3_clients": [
            {"client": c, "depenses": round(m, 2)} for c, m in top_clients
        ],
        "top_3_produits": [
            {"produit": p, "quantite_vendue": q} for p, q in top_produits
        ],
    }


def formater_rapport_console(rapport: Dict[str, Any], lignes_ignorees: int) -> str:
    """Génère un affichage textuel élégant et tabulé pour la console."""
    lignes: List[str] = [
        "=" * 68,
        "          📊 RAPPORT D'ACTIVITÉ COMMERCIALE & FINANCIÈRE",
        "=" * 68,
        f"💰 Chiffre d'affaires brut : {rapport['chiffre_affaires_total']:>12,.2f} €",
        f"📦 Nombre de commandes     : {rapport['nombre_commandes']:>12}",
        f"🏷️  Articles vendus au total : {rapport['total_articles_vendus']:>12}",
        f"🛒 Panier moyen par commande: {rapport['panier_moyen']:>12,.2f} €",
        f"⚠️  Lignes erronées écartées : {lignes_ignorees:>12}",
        "-" * 68,
        "📁 VENTES PAR CATÉGORIE :",
        f"{'Catégorie':<18} | {'CA Réalisé (€)':>15} | {'Part (%)':>10} | {'Articles':>8}",
        "-" * 68,
    ]

    for cat in rapport["categories"]:
        lignes.append(
            f"{cat['categorie']:<18} | {cat['chiffre_affaires']:>15,.2f} | {cat['pourcentage_ca']:>9.1f}% | {cat['articles_vendus']:>8}"
        )

    lignes.append("-" * 68)
    lignes.append("🏆 TOP 3 CLIENTS (Valeur d'achat) :")
    for rang, c in enumerate(rapport["top_3_clients"], start=1):
        lignes.append(f"  {rang}. {c['client']:<25} : {c['depenses']:>10,.2f} €")

    lignes.append("-" * 68)
    lignes.append("⭐ TOP 3 PRODUITS LES PLUS VENDUS (Volume) :")
    for rang, p in enumerate(rapport["top_3_produits"], start=1):
        lignes.append(f"  {rang}. {p['produit']:<25} : {p['quantite_vendue']:>5} unités")

    lignes.append("=" * 68)
    return "\n".join(lignes)


def exporter_vers_json(rapport: Dict[str, Any], chemin_sortie: Path) -> None:
    """Exporte les indicateurs sous forme de JSON structuré et indenté."""
    with open(chemin_sortie, mode="w", encoding="utf-8") as f:
        json.dump(rapport, f, ensure_ascii=False, indent=4)
    print(f"💾 Rapport financier JSON exporté avec succès dans : {chemin_sortie.resolve()}")


def executer_pipeline(chemin_source: str = "ventes.csv", chemin_json: str = "resume_ventes.json") -> None:
    """Coordonne l'ensemble des étapes du pipeline d'analyse."""
    path_csv = Path(chemin_source)
    path_json = Path(chemin_json)

    # Génération automatique du fichier d'exemple si absent
    if not path_csv.exists():
        print(f"ℹ️ Aucun fichier '{path_csv}' détecté. Création d'un jeu de test...")
        creer_jeu_de_donnees_demo(path_csv)

    print(f"\n⏳ Analyse en cours du fichier : {path_csv.name}...")
    transactions, lignes_rejet = charger_et_nettoyer_ventes(path_csv)
    metriques = analyser_donnees(transactions)

    # 1. Rendu console
    rapport_texte = formater_rapport_console(metriques, lignes_rejet)
    print("\n" + rapport_texte + "\n")

    # 2. Rendu fichier JSON
    exporter_vers_json(metriques, path_json)


if __name__ == "__main__":
    executer_pipeline()
